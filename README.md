# Online Queue Service

A modern web application for managing online appointments with service scheduling and client booking system. 

## 🚀 Features

- Service Management: Create and manage services with descriptions and pricing
- Flexible Scheduling: Set working hours and available time slots
- Online Booking: Clients can book appointments through an intuitive interface
- Appointment Management: View, confirm, and cancel appointments
- Notifications: Build-in notifications and email reminders for upcoming appointments
- Admin Dashboard: Comprehensive management interface
- Responsive Design: Works seamlessly on desktop and mobile devices
